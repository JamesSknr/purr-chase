# PURR-CHASE
### Description
The game lets you take control of a cat honed in on profit, whilst navigating a volatile market with a constant flow of news creating a chaotic environment its important to think fast and move faster. Trading a new stock each round with tailored news events which can drift, spike or crash the stock 
### End Goal of Game
To generate as much profit as possible between 9am - 5pm 
### AI USAGE SCALE: 3
MODELS USED
Claude Pro

### DESCRIPTION
The game was are original idea with all artwork made by hand, the largest use of Claude was to assist in building the random walk algorithm which determines the movement of the stock in stock_market.gd and populating event.json to quickly give us a whole library of events to keep the game exciting. We then also used it to write tests and code to help us debug mainly for level_logic.gd, apart from that other section used small amount to assist in the human driven coding allowing us to develop faster.
